# Code of Conduct

This project adopts the **Contributor Covenant, version 2.1** as its
code of conduct. The full text is published at
<https://www.contributor-covenant.org/version/2/1/code_of_conduct/>
and is incorporated here by reference.

## Scope

The Code applies in all project spaces: issues, pull requests,
discussions, the project's GitHub repository, and any communication
that takes place in the context of the project. It also applies when
an individual is officially representing the project in public
spaces.

## Reporting

If you observe conduct that you believe violates this Code, you can
reach the project maintainer at:

**Email:** 161535588+kodych@users.noreply.github.com

Reports are reviewed promptly. Reporter identity is kept
confidential unless the reporter agrees otherwise. In any
communication with the person whose conduct is being reported,
the reporter's identity will not be disclosed, nor referenced in
a manner that could reasonably identify them.

Please note that **security vulnerabilities** in the Cauldron
software itself go through a different channel — see
[SECURITY.md](SECURITY.md) for the private-disclosure flow.

## Enforcement

The project maintainer is responsible for clarifying and enforcing
the standards described in the Contributor Covenant. Possible
responses range from a private clarification through a temporary
restriction on participation up to a permanent ban from the project,
proportional to the situation.
